# Goal
Complete native replacement for 8BitDo Ultimate Software X 1.4.9.0 (Windows UWP, .NET Native 2.2, no CIL) in Rust. Phase 1: every feature the Windows app offers for Ultimate 3E (logical PID 0x202f), over the 2.4 GHz receiver (USB 2dc8:3024, connected NOW) and Bluetooth. Other models: document dispatch only.
